8. PHOTO DOWNLOAD PIPELINE

For PHOTO:

URL
↓
yt-dlp extraction
↓
identify PHOTO
↓
identify real image source
↓
download
↓
validate
↓
send Telegram Photo
↓
send original/high-quality Document

The image download must use the actual source returned by the extraction layer.

If yt-dlp successfully downloads the image, use that file.

If yt-dlp identifies a real image URL but normal file downloading fails, implement a controlled HTTP fallback.

The fallback must:

* use the actual extracted image URL
* follow redirects
* have a timeout
* verify HTTP status
* save to the job temporary directory
* verify actual image content

Do NOT invent URLs.

Do NOT use random scraping.

Do NOT use image search.
